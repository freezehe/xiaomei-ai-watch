一块手掌大小的开发板，一块 1.75 英寸的圆形 AMOLED 屏。对它说一声「小美同学」，它会亮起一圈绿色的波纹认真听你说话，再用台湾腔甜甜地回答你——查天气、看股票、放音乐、聊天，全都可以。

这篇文章把它从芯片到云端完整拆开：整体架构、一次对话的完整链路、用到的技术、踩过的坑，以及源代码在哪里。

04 一次对话的完整链路

以「小美同学，今天上海天气怎么样？」为例，看看一句话在系统里走了哪些路：

1本地唤醒

麦克风一直开着，音频先经过乐鑫 AFE 做回声消除、降噪，再交给 WakeNet9 模型。模型在板子上运行，不联网，听到「小美同学」才会进入下一步。

2建立连接

开机时，设备先访问 OTA 接口，拿到 WebSocket 地址和访问令牌；唤醒后用这个令牌建立 WebSocket 连接，并把唤醒词这段音频一起发给服务器。

3上行语音

你说话的声音被压缩成 Opus 格式，每 60 毫秒一帧，源源不断地发到服务器。屏幕上的光球变成绿色波纹。

4断句 + 识别

服务器用 Silero VAD 判断你什么时候说完，同时把音频流式交给火山引擎语音识别，得到文字「今天上海天气怎么样」，推回设备显示成右侧的紫色气泡。光球切换成橙色旋转，表示「思考中」。

5大模型 + 工具调用

文字交给豆包 Seed 2.1 Lite（实测首个字约 0.87 秒）。模型判断需要查天气，发起 Function Call，服务器执行天气插件、拿到结果，再让模型组织成口语化的回答。

6流式合成

模型一边输出文字，服务器一边送进火山双向流式 TTS（音色「湾湾小何」），不用等整段话写完就开始合成，首句延迟很低。

7下行播放 + 界面

合成的语音同样以 Opus 帧推回设备，解码后从喇叭播放；每一句的文字、以及大模型给出的情绪（开心、思考…）也通过 WebSocket 推回来，屏幕上显示成左侧气泡和对应表情。光球变成青色律动。说完自动回到聆听，可以接着问。

小结：链路里只有「唤醒」在本地，其余全部走云端；每一环都是流式的——边说边传、边识别边想、边想边合成、边合成边播放。这就是它反应快的原因。
05 我在开源项目上做了什么

站在三个优秀开源项目的肩膀上：设备端 AI 用小智 xiaozhi-esp32，桌面用乐鑫的 ESP-Brookesia，服务端用 xiaozhi-esp32-server。在这之上，我主要做了下面几件事。

双系统：一块板子两套固件

桌面固件和小智固件各占一个 OTA 分区。在桌面点「AI Chat」，程序把启动分区切到小智并重启；在小智里长按按键，或者直接说「回到桌面」（注册成了 MCP 工具，大模型可以调用），再切回来。

这里有个坑：写启动分区时 Flash 缓存会暂时关闭，而界面线程的栈放在 PSRAM 上，直接调用会触发断言导致死机。解决办法是专门开一个任务去写，因为 FreeRTOS 新建任务的栈默认在内部 RAM。

📷 截图位：esp32-s3-touch-amoled-1.75.cc · ReturnToDesktop()

设置应用：在屏幕上手动选 Wi-Fi

原来只能用手机连板子的热点、在网页里配网，换个地方就很麻烦。现在桌面上多了一个「设置」应用：扫描附近网络（按信号排序，显示加密锁和信号格），点一下输入密码就能连，也能忘记已保存的网络。

📷 截图位：设置应用——网络列表 + 密码键盘（实物照片）

关键设计有三点：

✅ 和小智共用一份 Wi-Fi 配置。保存格式和小智的 SsidManager 完全一致（ssid / password / channel 三组键，最多 10 个），切到 AI 以后直接用同一个网络，继续连阿里云后端。

✅ 连上了才保存。输错密码不会弄乱已保存的列表；同一个配置区里还存着服务器地址，程序只改 Wi-Fi 相关的几个键，保证服务器地址不会丢。

✅ 单任务状态机。Wi-Fi 事件和界面操作都放进同一个队列，由一个后台任务按顺序处理：没有多线程抢数据的问题，写 Flash 也一定发生在安全的内部 RAM 栈上。

专业聊天界面：为圆屏重新设计

小智原来的界面是一个表情加一行字幕，放在圆屏上显得简单。我参考智能手表，重新做了一套深色玻璃风格的界面：顶部状态图标、中间半透明的状态胶囊、会随状态变化的光球，以及可以上下滑动的对话气泡。

连接中● 蓝色旋转弧

圆屏的难点在于四个角都是看不见的：每个控件的位置都要按「距离圆心 d 处，可用半宽 = √(233² − d²)」来算，保证文字不会被切掉。另外，所有改动都放在板级文件里，小智的公共代码一行没改，以后跟进上游版本更新也很方便。

唤醒词：从「你好小智」到「小美同学」

我最初想要「小美小美」，但乐鑫的唤醒词模型库里没有现成的模型。比较了三种方案后，选了官方训练好的「小美同学」：

方案效果代价
WakeNet9「小美同学」✔官方模型，准确率高、误唤醒少只改两行配置
MultiNet 自定义「小美小美」识别率偏低、误唤醒偏多多占几 MB 模型空间和内存
找乐鑫定制训练最好收费，要等几周

改动就是板级配置里的两行：

// main/boards/waveshare/esp32-s3-touch-amoled-1.75/config.json
"CONFIG_SR_WN_WN9_NIHAOXIAOZHI_TTS=n",
"CONFIG_SR_WN_WN9_XIAOMEITONGXUE_TTS=y"

编译时，唤醒词模型会被打包进 8MB 的资源分区，再叠加上我做的星云 / 极光背景皮肤，一起烧进去。服务器那边把 AI 的人设名字也从「小智」改成了「小美」，这样叫的名字和它的自称就对上了。

云端：2 核 3.6G 的小服务器也能跑

服务端部署在一台阿里云经济型 ECS 上（CentOS 7.9，2 核，3.6GB 内存，上面还跑着别的服务）。本地语音识别 FunASR 实测要占 3.1GB 内存，根本装不下，所以改用云端流式识别，整个容器只占约 175MB。

安全上做了三件事：

🔒 服务端的 OTA 接口会把访问令牌发给任何来访者，所以用 Nginx 把它藏在一个随机的秘密路径后面；

🔒 容器端口只监听本机，公网只开放一个 Nginx 端口；

🔒 WebSocket 开启 Token 鉴权，没有令牌或令牌伪造都会被拒绝（部署后逐项实测过）。

📷 截图位：.config.yaml · 人设 prompt（记得给 Key 打码）

自定义插件：让它会看股票

服务端的插件机制很友好：写一个 Python 函数，加上 @register_function 装饰器描述它能做什么，大模型就会在需要的时候自己调用。我写了一个查 A 股和指数行情的插件，数据来自腾讯财经的免费接口，不需要 Key。问一句「上证指数今天怎么样」，它就能说出点位和涨跌幅。

07 踩过的坑

PSRAM 栈 + 写 Flash = 死机

界面线程的栈在 PSRAM 上，而写 Flash 时缓存会关闭。凡是读写 NVS、切换启动分区的操作，都要放进单独创建的任务里执行。

一句话被切成两半

「帮我把音量调到 60，然后讲个笑话」只识别出了前半句。原因是句尾静音判定默认 200 毫秒太短，调到 500 毫秒就能完整保留，只多等约 0.3 秒。

模型 404

豆包的 API 一直返回 404，最后发现是账号还没在控制台开通对应模型，而且有的版本号本身就访问不到。建议逐个版本实测。

共享配置区里的「邻居」

Wi-Fi 列表和服务器地址存在同一个 NVS 命名空间里。如果图省事整个清空，服务器地址会跟着丢，设备就再也连不上后端了。所以只能逐个键改写。

09 写在最后
